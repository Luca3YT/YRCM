# YRCM – YouTube Reaction & Chat Milestone

YouTube Live のリアクション数（ハートなど）をリアルタイムで集計し、マイルストーン達成時に OBS オーバーレイでエフェクトを表示する Windows 向けデスクトップアプリです。

---

## 機能

| 機能 | 説明 |
|------|------|
| 🎯 リアクション集計 | YouTube Live のリアクションをリアルタイム集計 |
| 🏆 マイルストーン演出 | 達成時に OBS オーバーレイでエフェクト・効果音を表示 |
| 👥 同時接続数 | 約10秒ごとに視聴者数を自動更新 |
| 📈 視聴者数グラフ | バナーの視聴者数をクリックで折れ線グラフ展開 |
| 💬 チャットコマンド | `!progress` などで視聴者が進捗確認可能 |
| 📊 配信サマリー | 配信終了時に総数・時速・達成マイルストーンを表示、Discord 用テキストをコピー可能 |
| 🔄 自動アップデート | GitHub Releases 経由で自動ダウンロード・更新通知 |
| 🎯 目標リスト | 自分で決めた目標の進捗を管理画面に表示、達成時に通知 |
| 🔔 サウンド | 達成音5種＋カスタム音源（WAV / OGG 推奨）・音量調整 |
| 💬 Discord 連携 | 配信サマリーを WebHook で Discord に送信 |
| 🎨 テーマ切替 | スタジオ / ネオン / ミニマルの3種類。管理画面とオーバーレイの両方に反映 |

## インストール

### EXE で使う場合（推奨）

1. [Releases](https://github.com/Luca3yt/YRCM/releases/latest) から `ReactionMilestone Setup x.x.x.exe` をダウンロード
2. インストーラーを実行
3. 起動後、管理画面が自動で開きます

アップデートは自動で検出・ダウンロードされ、再起動時に適用されます。

### 開発環境

```bash
git clone https://github.com/Luca3yt/YRCM.git
cd YRCM/reaction-electron
npm install
npm start
```

**必要環境:** Node.js 18以上 / Windows 10以上

## 使い方

### 1. OBS にオーバーレイを追加

1. YRCM を起動
2. OBS を開き「ソースを追加」→「ブラウザ」を選択
3. URL に `http://localhost:3000/overlay.html` を入力
4. 幅・高さを配信解像度に合わせる（例: 1920×1080）
5. **ブラウザソースを右クリック →「キャッシュを更新」を必ず実行**

> ⚠️ キャッシュ更新を行うまでオーバーレイ全体に赤い警告が表示されます。正常に更新されると自動で消えます。

### 2. YouTube Live に接続

1. 管理画面（`http://localhost:3000/admin.html`）を開く
2. 配信中の YouTube Live URL または動画 ID を入力
3. 「接続」ボタンをクリック
4. 上部バナーに配信タイトルと同時接続数が表示されれば接続完了

### 3. 配信終了

「🎬 配信終了」ボタンをクリックすると配信サマリーが表示されます。  
Discord 用テキストをワンクリックでコピーできます。

## チャットコマンド

視聴者がチャットに投稿すると、オーバーレイに進捗トーストが表示されます。

| コマンド | 説明 |
|----------|------|
| `!progress` / `!prog` / `!p` | 現在のリアクション数・進捗バー・時速を表示 |
| `進捗` / `どのくらい` / `どこまで` | 日本語コマンド（上記と同じ動作） |
| `!進捗` / `!どのくらい` | 感嘆符付き日本語コマンド |

クールダウン: 10秒（連打防止）

## 管理画面

管理画面（`http://localhost:3000/admin.html`）では以下の操作が可能です。

- **接続 / 切断 / 配信終了**
- **視聴者数の手動更新**（👥 更新ボタン）
- **同時接続数グラフ**（バナーの視聴者数をクリックで展開）
- **システムログ / リアクションログ** の確認・クリア
- **コマンドリスト** の確認（クリックで展開/折りたたみ）
- **アップデート確認・適用**
- **目標リスト** の編集（タイトルをクリック）
- **サウンド** の種類・音量・カスタム音源の設定
- **テーマ** の切り替え（設定カード。OBS のオーバーレイにも即反映）
- **Discord WebHook** の設定（設定カード）

> カードの並びは固定2カラムです（ドラッグでの並び替えは v1.5.5 で廃止）。

## 開発者向け

### ビルド・リリース

```bash
# ローカルビルドのみ（GitHub にアップロードしない）
npm run build

# GitHub Releases にリリース
set GH_TOKEN=ghp_your_token_here
npm run release
```

リリース後、GitHub の Releases ページで Draft を **Publish** にしてください。

### ディレクトリ構成

```
reaction-electron/
├── main.js          # Electron メインプロセス・自動アップデート
├── preload.js       # IPC ブリッジ（レンダラー ↔ メイン）
├── server.js        # HTTP / WebSocket サーバー・YouTube API 処理
├── admin.html       # 管理画面 UI
├── overlay.html     # OBS オーバーレイ
└── package.json
```

### WebSocket メッセージ一覧

| type | 方向 | 説明 |
|------|------|------|
| `milestone` | S→C | マイルストーン達成通知 |
| `progress` | S→C | !progress コマンド実行結果 |
| `viewers_update` | S→C | 視聴者数更新（history 配列付き） |
| `session_summary` | S→C | 配信サマリー（切断時） |
| `yt_status` | S→C | YouTube 接続状態変化 |
| `sys_log` | S→C | サーバーサイドのエラーログ |
| `reaction_log` | S→C | リアクション集計ログ |
| `theme_update` | S→C | テーマ変更（overlay 用） |

### 使用技術

- **Electron** 29 – デスクトップアプリ基盤
- **electron-builder** – Windows インストーラービルド
- **electron-updater** – 自動アップデート
- **Node.js** http / https / zlib – YouTube InnerTube API 通信
- **WebSocket** – リアルタイム通信（Node.js 標準モジュールで自前実装）
